# 筆畫精靈冒險島 — 國小一年級「基本筆畫名稱與寫法」互動練習與 A4 學習單套件

專為台灣國小一年級學生設計的教育部標準 30 基本筆畫筆順書寫、語音朗讀、遊戲化收集小精靈練習網頁與 A4 可列印學習單全套資源。

- 🌐 **線上體驗網址**：https://x9179996-sudo.github.io/stroke-writing/
- 📋 **30 筆畫中心線對照審閱頁**：https://x9179996-sudo.github.io/stroke-writing/debug.html
- 📄 **可列印 A4 學習單網頁**：https://x9179996-sudo.github.io/stroke-writing/print.html
- 📑 **高品質向量 A4 學習單 PDF (全 5 頁)**：[筆畫學習單.pdf](筆畫學習單.pdf)

## 專案架構與檔案清單

```
20261119_筆畫名稱/
├─ index.html                  ← 遊戲化練習主網頁 (單檔無相依，含冒險地圖、描寫關卡、小測驗、老師示範、家長專區)
├─ debug.html                  ← 30 筆畫幾何與中心線對照審閱頁 (標記綠起點、紅收點、橘折點、方向箭頭)
├─ print.html                  ← 可列印 A4 學習單網頁 (3 頁描寫單 + 1 頁連連看配對單 + 1 頁解答頁)
├─ 筆畫學習單.pdf              ← 高品質向量 A4 學習單 PDF (全 5 頁標準 A4，每格 2.3cm 見方，字級 18pt)
├─ strokes.js                  ← 30 個基本筆畫幾何外廓、中心骨架點、注音、例字、小精靈資料庫
├─ engine.js                   ← 描寫判定演算法引擎 (起訖點半徑、順序檢查點、容許寬度、方向防呆)
├─ fonts/
│  ├─ TW-Kai-98_1.ttf          ← 教育部標準楷書 (CNS11643 全字庫正楷體，供例字與筆形精準呈現)
│  ├─ TW-KAI-LICENSE.txt       ← 教育部楷書授權條款 (政府資料開放授權條款 v1.0 / SIL OFL 1.1)
│  ├─ BpmfIansui.woff2         ← 帶注音開源字型 (芫荽注音字型)
│  └─ BpmfIansui.ttf           
├─ tools/
│  ├─ test_judge.js            ← Playwright 30×3 (90項) 自動化描寫判定測試腳本
│  ├─ make_pdf.js              ← Playwright 自動渲染 print.html 產生標準 A4 PDF 腳本
│  ├─ verify_pdf.py            ← Python pypdf 讀取並檢驗 PDF 頁數與實際每頁尺寸腳本
│  └─ verify_and_screenshot.js ← 自動化量測實際計算字級並擷取平板與 PDF 截圖腳本
├─ screenshots/                ← 驗收截圖
│  ├─ debug.png                ← debug.html 全貌對照審閱截圖
│  ├─ tablet_1_home.png        ← 平板 (1024×768) 首頁冒險島地圖截圖
│  ├─ tablet_2_practice.png    ← 平板 (1024×768) 關卡描寫畫面截圖 (#13 橫折鉤)
│  ├─ tablet_3_quiz.png        ← 平板 (1024×768) 小測驗畫面截圖
│  ├─ tablet_4_parent.png      ← 平板 (1024×768) 家長專區畫面截圖
│  └─ pdf_page_1.png ~ 5.png   ← 學習單全 5 頁個別完整截圖
├─ package.json                ← 專案設定與 NPM 測試腳本
├─ .gitignore                  ← Git 忽略設定
├─ .nojekyll                   ← GitHub Pages 靜態網站相容檔
└─ README.md                   ← 本專案完整說明文件
```

## 執行與自動化測試指引

- **執行描寫判斷 30×3 自動化測試**：
  ```bash
  node tools/test_judge.js
  ```
- **生成 A4 學習單 PDF**：
  ```bash
  node tools/make_pdf.js
  ```
- **量測字級與截圖驗證**：
  ```bash
  node tools/verify_and_screenshot.js
  ```
- **驗證 PDF 每頁尺寸與頁數**：
  ```bash
  python tools/verify_pdf.py
  ```
